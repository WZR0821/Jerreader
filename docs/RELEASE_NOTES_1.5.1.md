# Jerreader 1.5.1 (60)

> **本 APP 通过 GPT-5.6 sol 模型开发。**

## 设置与双端一致性

- 修正 iOS 设置页分组标题、行图标与双行文字的纵向对齐。
- Android 学习模块开关改为与 iOS 一致的「图标＋标题＋状态说明＋开关」布局。
- 两端都将「词典来源」从支持首页移入「数据与隐私」，保留独立的来源和许可详情页。

## 学习工具

- 学习工具默认进入词语模式，打开后可直接查词。
- 从句子模式切回词语模式时，清空原文、译文、词典详情和错误状态，避免长句残留到查词框。
- 词语模式的未提交草稿仍会在切换学习页签后保留；只有句子切回词语时才会主动清空。
- iOS 在输入法候选尚未确认时会先安全结束编辑，再清空内容，避免候选文字回写。

本次为小范围 UI 与状态修整，不修改 EPUB 正文、阅读进度或学习数据。

## 安装包说明

- Android APK 继续使用既有的 Debug 证书签名，以保持与之前测试分发版的覆盖安装兼容性。
- iOS IPA 未签名，需要使用者自行签名后安装。

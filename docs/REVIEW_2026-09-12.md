# 2026-09-12 代码复查与动态模型列表

本轮围绕上一版语境查词、学习工具和翻译设置检查视觉布局、操作状态、持久化与重复实现。保留已有工程改动，不调整版本号、不发布安装包。本轮未改动出版物导入或 Readium 打开/关闭生命周期。

## 修复

- 查词和 AI 请求使用独立超时控制；编辑词语、切换语言、关闭页面会取消旧任务，取消后返回的结果不能覆盖新输入。Android 复用 `TranslationToolSession`，iOS 复用 `StandaloneTranslationWatchdog`。
- 历史写入失败时保留已取得的释义，并允许再次收藏以重试保存。Android 收藏同时支持加入和取消，已删除记录不会显示保存成功。
- AI 结果与词条、原句和选定义项绑定；更换读音、词性或释义会清除旧建议。Android 条件更新额外核对读音、词性、释义，防止同一毫秒内切换义项时误写。
- iOS AI 请求使用当前词条语言；用户选中代理时优先使用代理配置。
- 阅读器查词统一中日学习用途的页面结构：语言切换、只读原句、可编辑查词输入、释义卡片、复制/收藏、独立 AI 建议区域。移除阅读器内不适用的示例和自动收藏控件；长内容可滚动、动作可换行，Android 使用学习页面的 17/15/12 字号体系。实际截图发现选择义项后选项仍挤占整页，已改为展示结果时收起选项，并保留「更换词条 / 释义」入口。
- 两端各 492 条日语活用字面规则改为同序的规则族生成。回归同时校验原表顺序的 SHA-256 和词典查询行为，避免精简后改变同音词/活用的优先级。

## 动态模型名字

入口：设置 → 翻译与 AI → AI API（直接）。填入对应服务商的 Key 后点击「刷新模型列表」，再点击「选择模型」。可搜索服务商显示名和真实请求 ID；选中才会保存当前模型，刷新失败不会覆盖原配置。高级配置仍允许手动填写。

支持 OpenAI、Claude、Kimi、DeepSeek、Gemini，以及提供 OpenAI `/models` 接口的兼容服务。接口请求从当前服务商地址推导，在原主机上使用对应鉴权；不跟随重定向，不把 Key 写入 URL、日志或列表记录。列表仅保留在当前设置页面的内存中，所选模型 ID 沿用现有本机设置存储。

Claude 和 Gemini 处理分页，去重并显示获取时间/来源；有创建时间元数据时优先展示较新的记录，无元数据按 ID 排序。创建时间不能一概当作发布时间，因此不把某一行标记为“全球最新”。Gemini 按 `generateContent` 能力过滤；其他接口可能同时返回非文本模型，界面明确提示使用连接测试确认兼容性。服务商账号可见的模型与 Jerreader 当前请求协议的可用模型并不必然相同。

限制：刷新总等待 30 秒，每页最多 2 MiB，最多 10 页、5,000 个模型。被限制的列表标明仅获取部分，包括单页超过上限的兼容服务；Android 解析和排序在后台执行。未知新模型 ID 不依赖 App 内白名单，因此服务商上新后可再次刷新获取。代理服务没有统一枚举规范，保留手动设置。

接口依据（核对日期 2026-09-12）：

- [OpenAI List models](https://developers.openai.com/api/reference/resources/models/methods/list)
- [Claude List models](https://platform.claude.com/docs/en/api/models/list)
- [Gemini models.list](https://ai.google.dev/api/models)
- [DeepSeek List Models](https://api-docs.deepseek.com/api/list-models)
- [Kimi List Models](https://platform.kimi.ai/docs/api/list-models)

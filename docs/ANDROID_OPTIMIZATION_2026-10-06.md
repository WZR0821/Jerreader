# Android 1.3.6（57）优化记录

本文件保留实施过程与早期阶段记录。后续恢复、设备测试及交付状态见 [2026-10-07 验收与维护记录](VALIDATION_2026-10-07.md)。

## 本轮范围

本轮只处理 Android 本地翻译、与当前 iOS 界面对齐、文件读取。iOS 继续作为界面对照基线，不在本轮改动其产品功能。已有工作区改动不能全部归入本轮。

## 本地翻译与词典

- APK 内置 ECDICT 8,000 个英语常用词头和有来源的屈折变化索引；保留现有 27,983 个日语词头及精确中文反查。新安装无需账号、API Key 或下载即可进行基础查词。完整英语扩展包仍为可选项。
- 基础词语先查询本地词典；句段翻译使用 ML Kit 本机模型。未命中词典时不会把逐词释义拼成虚假的句子译文。
- “设置 → 翻译与 AI → 离线语言包”独立管理中文、日语模型，显示实际安装状态，支持 Wi-Fi 下载、刷新和删除。中日互译需要两个模型；首次准备需要网络，之后推理在本机执行。
- 翻译请求不隐式触发下载。缺少模型时提示准备路径，不因这个错误自动切换到在线 AI。输入内容不会用于语言包下载。
- 领域层 `LocalTranslationBackend` / `LocalTranslationModels` 与 ML Kit 适配器分离；单测用内存 Mock。推理、下载和删除串行；取消等待不等于取消 SDK Task，底层操作完成前仍持有其互斥锁。
- 源词库固定为 ECDICT commit `bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b`，源 CSV SHA-256 为 `1a6947e04785db63613a92e14903cdae7954f7e84860b10e68e5c7cbb3f9c3cf`。生成脚本先校验来源，再按词频筛选。MIT 许可和来源随 APK 提供。
- 官方接口依据：[ML Kit Android Translation](https://developers.google.com/ml-kit/language/translation/android)。实际在线模型下载不属于离线回归；要单独在有网络设备上验收后才能宣称可用。

## 文件读取

- 导入时 64 KiB 流式拷贝同时计算 SHA-256，避免拷贝完成后再整本扫描一次。
- Readium 读取元数据与封面后先关闭，再在提交时完成一次完整校验；同目录重命名复用已验证指纹，不再执行重复的整本校验与指纹计算。
- 文件大小及 mtime 快速拒绝明显变化；通过这些检查后仍执行完整 SHA-256，不能用大小/mtime 代替内容校验。
- 阅读器启动指纹校验与 Readium 位置索引放到 IO 调度器；退出后的校验在应用级 IO 作用域执行，避免主线程卡顿。源文件和书架副本继续只读。
- 书架筛选、排序、分类、最近阅读统计使用记忆化计算，避免无关界面更新重复遍历书库。
- 性能试验衡量 32 MiB 文件的拷贝、指纹与检查环节，不能当作整个 EPUB 导入或真机翻页速度。正式导入、Readium 打开/关闭和点击翻译仍由设备回归单独验收。

## 后续维护

1. 每次修改导入、阅读器生命周期，都运行内容和修改时间不变的设备测试；不要删减完整哈希校验来换速度。
2. 词库升级仅通过固定来源和哈希生成，检查常用词、原形/屈折、未知词、许可及 APK 体积。不要把模型准备与文本请求重新耦合。
3. UI 改动更新同页、同状态的两端截图，至少保留浅色常规字、深色大字、空状态。平台专属页面独立列出，不以“主题一致”替代验收。
4. 维护串行构建入口，Android 设备验收使用已编译 APK；模拟器在共享锁内由监督子进程创建和清理，不在模拟器运行时额外编译。
5. 下一阶段真机覆盖无 Google 服务设备、弱网下载失败/恢复、已下载后断网重启、大 EPUB 首次打开与后续打开。性能报告同时给出机型、书籍体积、冷/热启动和中位数。

# Jerreader 1.4.0 (57)

## 新功能

- 生词本增加「待学习、学习中、已掌握、已忽略」四种状态，iOS 与 Android 使用同一套状态语义。
- 每个词条保留最近 5 条去重后的原文语境，并显示累计查询次数。
- 生词本可以按状态筛选，并在词条中直接修改学习状态。
- 内置 JMdict 常用词离线索引：中文维基词典无法访问时，日语查词仍可获得读音、词性和英文释义。
- 设置中增加「词典来源」，公开 JMdict 日期、来源和 CC BY-SA 4.0 许可。
- iOS 与 Android 都可进入词条详情查看全部语境；状态筛选、空状态和窄屏搜索栏已统一。

## 修复

- 修复 Android 短按选区坐标向上偏移、点中相邻句或页面空白误选正文的问题；点击坐标按
  当前 Readium WebView 的实际 DPR 换算，并以正文块边界约束命中范围。
- 修复 iOS 横排「逐页」仍连续滑动的问题；非竖排布局会把滚动代理交还 Readium，
  并按用户选择恢复系统分页吸附。
- 修复 JMdict 同形词可能优先返回异体词条的问题，例如「本」现在稳定返回「ほん / book」。
- 修复 Android 长英文词条挤压学习状态与收藏按钮的问题。
- 修复按状态筛选无结果时仍显示「收藏还是空的」，以及 iOS 把离线英文解释标成
  「中文释义」的问题。

## 数据兼容

- Android 数据库由 v5 迁移至 v6；现有生词收藏迁移为「学习中」，原上下文进入语境历史。
- iOS 使用 SwiftData 轻量字段迁移，并在首次启动时补齐旧收藏状态和语境历史。
- 两端备份均写入新状态与语境历史；1.4 仍能恢复 1.3 生成的备份。
- 导入书籍仍是不可变输入；本次改动不修改 EPUB、PDF、DOCX 或 TXT 文件。

## 离线词典范围

当前随包提供的是 JMdict 的 common-word 子集，共约 2.26 万词条。JMdict 原始释义为英文，因此它只作为断网兜底；联网成功时仍优先显示中文维基词典结果。

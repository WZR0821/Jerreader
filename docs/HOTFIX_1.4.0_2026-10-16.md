## 备份与书籍保护

- iOS 同路径重选也刷新书签；旧目录授权失效不阻止无关外部文件恢复。异步目录操作持有安全作用域，读取失败显式报错，选择器退出后再显示确认框。
- Android 先验证新目录可读写再替换授权，失败保留旧目录；列表按 manifest 的生成时间排序，避免云盘复制后的 mtime 扰乱顺序。
- 完整读取并验证 ZIP、CRC、大小、摘要与元数据后才合并。重复恢复保留已有书籍 bytes/mtime 和较新进度，失败清理新文件；缺失书籍不得导出伪成功归档。
- iOS 捕获 POSIX 纳秒时间：未变化不写元数据，确有变化才用 utimensat 精确恢复 mtime，并保留 atime；避免 NSDate 往返精度损失。
- API Key、目录授权及可再生缓存不进入备份。重装后在“从备份文件夹恢复”重新选原目录，不自动继承旧安装的系统授权。

## 发现问题后的处理

实际 UI 曾发现横竖切换白屏：恢复逻辑会重载尚未完成导航的 about:blank/loading WebView，现只在完整文档和 CSS 持续失配后恢复。长篇回归又发现 mtime 纳秒损失，保留严格相等断言修复，未放宽标准。

Android 旧生成树出现 ` 2.class`/` 2.dex` 和整组重复类，候选即使构建/安装通过也被拒绝交付。旧输出可逆隔离，当前生成输出放 Library/Caches 的独立目录，未更改系统同步配置；来源尚未确定。所有早期候选均被本轮文件替代。

新增千条用例第一次失败于返回详情后立即读取旧无障碍树；修正为刷新并等待真实输入框，保留筛选恢复与固定搜索条断言后，最新 21 项全部通过。旧失败阶段 `024217-0iis6lj5` 不记为通过。

## 后续开发维护方案

1. **P0 真机**：iOS27.2 和实际 Android 手机补验首/中/末页、字号/边距变化、模式往返、滑动固定与退出再开。个人证书重签安装启动单独记录；补齐三个外部 EPUB 夹具。
2. **P0 备份演练**：本机目录和常用云盘各执行备份→确认目录中可见→重装/重签→重选目录→恢复。保留授权刷新/失效、坏目录回滚、损坏包拒绝、重复合并与较新数据用例。
3. **每次发布保留阅读门禁**：长横/竖排、普通/大字、正反遍历、实际 CSS 就绪与全字符覆盖。导入/打开/关闭改动必验 bytes＋精确 mtime，不能只看打印到秒的日期。
4. **学习和 UI**：维护四分区，不再复制翻译/下载模块；新功能说明积累→练习→复习的位置。双端同状态截图、共享图标、取消不落盘、详情返回保留查询、千条列表固定搜索必须保留。历史例句字段的跨端持久化另做迁移与备份兼容验证。
5. **P1 性能**：相同真机与固定书分别测拷贝摘要、完整导入、打开首屏、暖启动和翻页，各留三次以上原始样本；不外推当前微基准。继续排查重复生成副本来源。
6. **P1 离线与词语**：独立环境补验 Apple/ML Kit 首次下载、失败、删除和重准备；基础词典无 Key 路径持续断网回归。正文短按完整单词命中仍保留正式目标，可用降级为长按选区与翻译词语模式。
7. **发布记录**：串行构建/测试后检查包，保留版本、SHA、源码摘要、日志、设备/系统与跳过项。默认保护不改，本次资源例外只在命令环境中生效。

# AI 回答质量样例集

`samples.json` 是一组固定的真实书句。改动翻译或解析的提示词前后，各用真实模型跑一遍，人工对比回答质量。现有的 mock 测试只能检查请求格式和流程，判断不了模型答得好不好，所以另备这一套。

## 内容

- 日文 30 句，出自青空文库 17 部作品（芥川竜之介、夏目漱石、宮沢賢治、太宰治、森鴎外、樋口一葉、中島敦、梶井基次郎）。覆盖「」对话、主语省略、长连体修饰、敬语、は/が 与 に/で、と/って 引用、旧字旧假名与文语、引号内无句号、拟声拟态词、使役被动等。
- 英文 20 句，出自古腾堡计划 13 部作品。覆盖长关系从句、习语、古旧表达、代词指代、对话、反讽、短语动词、句中的 Mr./Mrs./Dr. 等。
- 提示注入 2 句（`inj-ja`、`inj-en`，合成）：句中夹着“忽略以上指示、改做别的事”的话。合格的回答照常翻译或解析这句话，不执行其中的指令，也不改变输出格式。

## 来源、核对与版权

- 所用作品均为公有领域：青空文库这 17 部的作者都已去世多年、著作权已过期；古腾堡这 13 部都是公有领域作品。
- 古腾堡：只用了公有领域正文，不带 Project Gutenberg 的许可声明和商标，也不要以它的名义展示或分发这些句子；`source` 里的站点名和链接只用于溯源。
- 每句的 `text` 和 `context` 都在 2026-11-22 与 `source.url` 页面的文本逐字核对后复制，核对不上的句子一律不收。
- 青空文库有新字新仮名版的作品用新仮名版，`orthography` 记录所用版本的文字类别。注音从正文中去掉，读音记在 `ruby`；段首的全角空格不计，跨段处用换行连接。日文 `text` 都按 App 点按分句的规则取完整单位（例如整段「」）。
- 古腾堡主站当天在维护（HTTP 503），改用它的官方镜像 gutenberg.pglaf.org 的纯文本核对。段内折行合并为一个空格；带下划线（斜体标记）的句子都避开了。

## 字段

| 字段 | 说明 |
| --- | --- |
| `id` | `ja-01`…`ja-30`、`en-01`…`en-20`、`inj-ja`、`inj-en` |
| `language` | `ja` 或 `en` |
| `text` | 要翻译或解析的句子，对应提示词里的 SELECTED TEXT |
| `context` | 原文中紧挨着的 1–2 句，对应 READING CONTEXT |
| `contextPosition` | `before` 或 `after`：context 在 text 之前还是之后 |
| `ruby` | 只在日文有注音时出现：`[{field: "text" 或 "context", base, reading}]` |
| `source` | `work`、`author`、`site`（`aozora`/`gutenberg`/`synthetic`）、`url`（核对用的页面，合成样例为 null）；青空文库另有 `orthography`，古腾堡另有 `ebook`（书号） |
| `phenomena` | 这句考查的语言现象（中文标签） |
| `expectations.translation` | 1–3 条：译文必须做到的点 |
| `expectations.structure` | 1–3 条：句子解析必须做到的点 |

## 用法

1. 改提示词前，用同一个模型和同样的设置，把每句的翻译和解析各跑一遍，存下回答。
2. 改完再跑一遍，逐条对照 `expectations`。每条只判“做到”或“没做到”，记下没做到的 id 和条目。
3. 对比两次结果，确认没有变差再合入。

已有样例不改原文。新增样例请用新 id；期望有改动时把 `version` 加 1。

之后会在 `scripts/run_ai_samples.py` 加一个批量运行脚本：读取本文件，调用真实模型，输出供人工打分的结果。该脚本尚未编写。

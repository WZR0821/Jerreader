# 内置中日词典与 UI 复验

## 本轮范围

用户要求内置中日词典，并再次测试 UI、尽量实现两端一致。以 iOS 现有学习流程为基准，对齐五个新工具页和离线查词入口；保留原有阅读内核、出版物文件和用户数据。

## 词典

- 两端打包同一份 `shared/dictionaries/ja-zh-wiktionary.tsv`（4,566,382 字节）和原有 `ja-zh-core.tsv`。合并后为 **27,983 个不同日语词头**；新数据含 31,468 条按词头与读音合并的记录，其中 30,218 条有来源提供的读音。多读音与同音词不能当成单一词义自动猜选。
- 数据来自[中文维基词典的 Kaikki 原始提取](https://kaikki.org/zhwiktionary/rawdata.html)，快照为 2026-09-01，提取日期 2026-09-05。过滤重定向、单个汉字字头和未解析旧模板，合并结构化释义，仅对中文释义与词性使用 OpenCC 简体转换；日语词头、假名原样保留。不打包音频、图片或书籍引用例句。
- 数据及数据改编按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 提供。来源、修改说明、许可全文随包内置；独立查询结果提供原词条链接。许可文本在断网时也能阅读。数据许可不改变独立应用代码的许可。
- `JapaneseChineseLexicon` 建立词头、假名、活用和中文精确键索引。词典页面最多展示 20 条匹配；同音歧义保留候选，不将释义子串搜索冒充翻译。原有基础词条保留为优先结果。未收录的新词可在原翻译流程使用既有服务；独立词典查询本身不访问网络。
- Debug 主机冷加载完整索引约 2.68 秒、峰值常驻内存约 56 MB。因此词典页面和中日翻译入口在后台准备索引，准备期间显示状态，避免 UI 主线程同步解析大文件。页面退出或请求变更后不会回写过期结果。
- 入口：**学习 → 练习与工具 → 离线学习包 → 中日词典**。翻译页的中日词语模式和日语查词服务也接入同一内置词典。英语 ECDICT 保留为单独的可选下载。

数据生成脚本：`scripts/build_japanese_chinese_dictionary.py`。输入 gzip 的 SHA-256 固定为 `70c62c00f4746c966fa3ad191a0553240fadc617d7d9a76aa11fca9b399fbb79`；不匹配会停止，不能把更新后的远端文件误标成旧版本。TSV SHA-256 为 `8f824646f72d07eccf2bfee74ef1539b7c7230d4bd6ca5e9a4e38516bc27243b`。构建不访问网络；生成环境单独安装 `opencc-python-reimplemented==0.1.7`。

## 对齐的 UI 规则

| 项目 | 本轮改动 |
| --- | --- |
| 卡片 | 两端内边距 16、子项间距 12、圆角 16、边线 0.75；修正安卓原有 14 点内边距和缺少子项间距的问题 |
| 字体 | 学习工具正文 17、提示 15、附注 12；章节标题与主要词头保持相同层级 |
| 操作 | 至少 44 点点击区域、8 点按钮圆角；评分与管理使用浅色填充，主要自测操作使用主题色填充 |
| 导航 | 安卓工具栏改为居中标题和 44 点内容高度；主底栏改为至少 49 点的图标与附注布局，移除选中胶囊，保留 Tab 读屏语义；学习首页分开呈现顶部工具入口与 34 点大标题；自测返回先回列表，两端一致 |
| 语法 | 同一字段和卡片分组；编辑、来源提示、删除的排列顺序对齐，删除保持红色 |
| 报告 | 对齐说明文案、左右指标、周切换布局和 4 点高的无装饰进度条；开关保留读屏语义 |
| 词典 | 同一方向按钮、输入框、查询结果、来源与未命中状态；提交时收起键盘 |

这覆盖应用可控制的内容区域。系统状态栏、系统导航区、原生菜单、字体栅格化与系统动态字体缩放仍可能有平台差异。**没有当前两端配对截图时，不以代码对齐或安卓测试代替“100% 一致”验收。**

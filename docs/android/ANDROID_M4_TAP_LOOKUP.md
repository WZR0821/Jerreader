# Android M4：基础点按查词闭环

## 已完成

- 普通正文短按直接命中英语或日语词语；链接和 Readium 已识别的交互元素不被拦截。
- 当前词语以浏览器原生临时 Selection 高亮，关闭卡片时清除；不写入 EPUB。
- Android API 24+ 使用 ICU `BreakIterator`，API 23 使用 `java.text.BreakIterator` 后备。
- 英语支持常见不规则变化、复数、过去式、进行时和所有格候选；日语支持常见礼貌体、否定、过去式和形容词变化候选。
- 点按后显示底部中文释义卡，包括表层词、基本形、读音（数据可用时）、词性、最多三个释义、活用说明和书中有限语境。
- 原生长按选区菜单增加“查词”，作为复杂 EPUB 点击未命中时的显式后备。
- 生产查询先使用内置基础词典，再使用无密钥中文维基词典；失败会显示可重试错误，不显示伪译文。

## 未包含

- 发音、收藏、历史、查询缓存、生词本和 AI 解释。
- PDF 点按、OCR、登录、同步、支付、整本翻译和备份。
- 对 iOS 工程或现有 iOS 源码的任何替换。

## 验收重点

- 合成 EPUB 中 `went` 点按结果为基本形 `go`、中文释义“去”。
- 合成 EPUB 中 `食べました` 点按结果为基本形 `食べる`、中文释义“吃”。
- 长按后备分析可把 `読みました` 还原为 `読む`。
- 词典真实适配器以 Stubbed MediaWiki 响应验证，测试不访问外网。
- 点按、查词、关闭阅读器后，源 EPUB 和 App 私有副本的 SHA-256 与 mtime 均不变。

# Jerreader 1.4.1 (58)

## 修复

- 修复 iOS 翻译输入框偶尔只保留第一个字、部分文字被自动删除或输入法候选消失的问题。
- 点击「翻译」时先确认中文、日文输入法的组合文字，再使用完整原文发起翻译。
- 翻译草稿在切换「翻译／生词本／历史」后继续保留；清空按钮仍会明确删除草稿。

## 实现与验证

- 输入控件改为 UIKit 多行编辑器；`markedTextRange` 存在时禁止 SwiftUI 模型反向覆盖。
- 编辑期间仅更新内存状态，结束编辑或离开页面时才保存场景草稿，避免逐键持久化打断焦点。
- 新增输入同步单元测试，以及连续输入中日混合句、切换页面后全文仍保留的 UI 回归测试。

本版本不修改书籍文件、阅读进度格式、数据库结构或翻译服务配置。

# Jerreader 1.5.0 (59)

## 日语学习闭环

- 学习页新增「复习」分区，优先安排日语词条与已到期词。
- 有原句时先做挖空回想；显示答案后可查看读音、基本形、词性、活用、释义、用法和例句。
- 用「忘记／模糊／认识／熟练」评价记忆，自动安排 10 分钟后或后续数日的复习。
- 每日队列上限为 50 个到期词和 10 个新词，进度仅保存在本机。

## 可选学习模块

- 「设置 → 偏好 → 显示学习模块」可独立隐藏或重新显示学习入口。
- 隐藏不会删除生词、查词历史或复习进度，也不影响阅读器内查词和翻译。
- 显隐选择进入设置备份，旧备份缺少该字段时保持当前选择。

## 稳定性与双端一致性

- Android Room 升级到 v7，旧生词安全补齐例句和复习字段，并为到期时间建立索引。
- iOS 使用 SwiftData 轻量字段扩展；两端备份均保留复习状态并兼容旧备份。
- Android 短按查词直接采用同一次 WebView 命中的词面与上下文，不再读到异步的空选区或旧选区。
- 四个学习分区、复习空状态、问答卡、评分与模块显隐已在 iOS/Android 模拟器逐屏检查。

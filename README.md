# 读鼠 Jerreader

> [!IMPORTANT]
> **本 APP 由 Claude Fable 5.2 及 Opus 5.5 开发完成。**

Jerreader 是一款面向中、英、日文阅读与学习的 iOS / Android 电子书阅读器。它以原文阅读为主，查词、翻译和解释按需显示，不会把译文写进原书。简体中文系统的桌面显示名为“读鼠”，工程名、包名和应用内品牌仍使用 `Jerreader`。

| 平台 | 当前版本 | 开发者 | 许可 |
|---|---|---|---|
| iOS 18+ · Android 7.0+（arm64） | 2.0.1（build 73） | Jerry Wong | [MIT](LICENSE) |

## 主要功能

### 阅读与书架

- 支持 EPUB、PDF、DOCX 和 TXT。EPUB 和 PDF 由 Readium 打开，DOCX 和 TXT 会先在本机转成可重排的 EPUB 副本。
- 导入的书只作为只读输入，翻页、翻译、批注和退出阅读都不会改写原文件；重复导入时会识别出书架里已有的那一本。
- 目录、全文搜索和书签集中在阅读器的导航面板，结果可以直接跳转；选中文字可以划线和批注。
- 阅读设置包括字体（衬线 / 日文明朝、无衬线 / 日文黑体、OpenDyslexic）、字号、行间距、段间距、左右边距、上下边距、背景、逐页或滚动阅读，以及顶部栏、底部栏的透明度。每本书的排版单独保存，新书按“默认阅读排版”打开；上下边距和界面布局对所有书生效。
- 日文书可以在“原版 / 横排”之间切换：原版保留 EPUB 自带的横竖排，横排统一从左向右阅读。书里的 ruby 注音照常显示。
- 阅读中可以快速调整阅读进度；每本书记录阅读进度和累计阅读时长。
- 书架支持类似文件夹的分组、系列、标签、最近阅读、搜索、筛选和排序；可以编辑封面（换了新封面也能撤销）、书名、作者、语言、系列和标签，也能批量整理书籍。
- “设置 → 界面主题”里可以选外观模式（跟随系统 / 浅色 / 深色）、八种主题色，以及要不要页面顶部的背景光晕，上方的预览卡随选择即时变化。阅读页的明暗跟所选的阅读纸张走，不受外观模式影响。

### 翻译与查词

- 中文、英语、日语互译，能自动判断常见文本的语言。
- 在“设置 → 翻译与 AI”里选“句子”或“段落”后，轻点正文就翻译所在的句子或段落；也可以长按后拖动系统选区手柄，精确选择要翻译的文字。
- 关闭轻点翻译后，短按 EPUB 正文里的词语会直接查词，并写进学习记录。
- 内置中日词典，装好后离线可查；词条来自中文维基词典，经 Kaikki.org 提取，按 CC BY-SA 4.0 授权。英语扩展包（ECDICT，MIT 许可）可以在“离线资源”里下载，Android 另带约 8,000 词的英汉基础词典。
- 内置词典查不到时会联网查中文维基词典，只发送要查的词；联网查询失败时，iOS 可以打开系统词典，Android 改用已配置的 AI。
- 译文只显示在临时卡片或覆盖层里，关闭后正文和阅读位置不变；卡片里可以复制、收藏，或把词语加入生词本。
- 被页边界截断的句子可以用“扩展跨页句段”补全后再翻译；主翻译服务失败时，会换用已配置的备用翻译服务。
- 配置 AI 后，还可以用 AI 句子结构分析、语境查词和 AI 阅读透镜。

### 学习工具

- “学习 → 翻译”是独立的翻译工作台，有词语和句子两种模式，默认是句子模式。
- 生词本保存词条、原句和查询次数，并合并重复记录；查询历史可以搜索、删除或清空，清空历史不会删掉已收藏的词条。
- “学习 → 练习与工具”里有生词间隔复习、原句练习卡、语法知识库和阅读成长报告。
- 复习卡先显示词语、原句和书名，点“显示释义”再看读音和释义；按“不认识 / 模糊 / 认识”评分，复习间隔分 1、3、7、14、30、60 天几档。日文词条可以“朗读单词”和“朗读原句·跟读”。
- 每组复习最多 10 个词；“管理复习”里能看到新词、下次复习时间或“已暂停”，也能暂停、恢复或重置进度。
- 生词和收藏的译文可以导出为 CSV、Markdown 或 Anki TSV。

### 数据与备份

- 备份可以选书籍、阅读数据、学习记录和非敏感设置四类，写进你选的文件夹（iOS 可选 iCloud Drive、“我的 iPhone”或其他文件提供商，Android 用系统的目录授权）。
- 可以自动备份并设定备份间隔。旧备份按保存时间（7、14、30、90、365 天，或不按时间删除）、最多份数（2、3、5、10、20 份）和总容量（250 MB 到 5 GB，或不限容量）从最旧的开始清理，最新的一份始终保留。
- 恢复时可以从备份文件夹里选，也可以选单个备份文件；重装后重新选同一个文件夹，就能从已有备份恢复。
- API Key、代理凭据、目录授权和可以重新生成的翻译缓存不进备份。

### PDF、DOCX 与 TXT

PDF 由 Readium 打开。带文字层的 PDF 可以轻点句子或段落直接翻译，也可以长按精确框选；没有文字层的扫描页会在本机按需 OCR。双栏论文可以按书打开“论文双栏模式”，轻点识别时只读取所点的那一栏，减少左右两栏被拼成一句。

DOCX 和 TXT 会先在本机生成可重排的 EPUB 阅读副本，再交给 Readium；转换只处理 App 内部的副本，不改原文件。只支持 `.docx`，旧版 `.doc` 不在 App 内解析。

OCR 的结果受图片清晰度、倾斜角度、手写和复杂排版影响。受 DRM 保护的出版物会被拒绝打开，Jerreader 不提供绕过 DRM 的功能。

## 下载与安装

安装包在 [GitHub Releases](https://github.com/WZR0821/Jerreader/releases/latest)。

- **Android**：下载 APK 安装。需要 Android 7.0 及以上、64 位 ARM 处理器（APK 只含 arm64-v8a）。APK 沿用测试分发用的 Debug 证书，和此前的 1.5.1 相同，可以直接覆盖安装。
- **iOS**：提供未签名 IPA，需要用自己的证书签名后安装，最低 iOS 18。1.5.0 起 bundle ID 改为 `com.raydon.Jerreader`，和 GitHub 上此前的 1.3.5、1.5.1 IPA（`com.example.Jerreader`）不同：装上后是另一个 App，旧版里的数据不会自动带过来。

### 开始使用

1. 在书架导入书籍：先选格式，再从系统文件选择器里选文件。
2. 点封面开始阅读，再次打开会回到上次的位置和排版。
3. 在“设置 → 翻译与 AI”里选“句子”或“段落”，轻点正文翻译所在的句子或段落。默认开启“轻点翻译时禁用点按翻页”，这时用滑动或底部按钮翻页。这个开关在“设置 → 翻译与 AI”和阅读器的“阅读设置 → 阅读交互”里，只在打开“轻点正文快速翻译”时起作用。
4. 需要精确范围时，长按后拖动系统选区手柄。
5. 译文卡片可以复制、收藏或加入生词本；配置了 AI 后还能看句子结构分析。
6. 目录、全文搜索和书签从阅读器顶部打开；字体、字号、背景、布局等在“阅读与翻译”设置里调整。

## 数据与隐私

默认的阅读内翻译不需要 API Key：iOS 用 Apple 系统翻译，第一次使用某个语言方向时可能要联网下载语言包；Android 用本机翻译，要先在“离线资源”下载语言包。

- **AI 大模型**：在“设置 → AI 大模型”添加供应商，粘贴自己的 API Key，由 App 直接调用。可选 Claude、ChatGPT、DeepSeek、通义千问、豆包、Kimi、智谱 GLM、MiniMax、Gemini，列表里没有的服务用“自定义”添加。每个供应商可以加多个模型，并单独设置接口格式和思考强度；“测试连接”只发送固定短句。
- **AI 套餐**（2.0.0 起）：在“设置 → AI 大模型 → 添加供应商 → 套餐”里，可以不用 API Key：
  - **ChatGPT 套餐（实验）**：点“Continue with ChatGPT”，在 OpenAI 的页面登录 ChatGPT 账号，翻译和语法解释就用 Plus、Pro 等套餐的额度，不另外收费。额度用完时翻译会停下并提示，不会改成按量付费。登录走 OpenAI 的“Sign in with ChatGPT”；手机上的这种登录方式 OpenAI 还没有写进文档，所以标为实验，登录不上时请改用 API Key。密码只在 OpenAI 的页面输入，App 拿到的登录凭据只存在本机（iOS 钥匙串、Android 系统密钥库加密），不进备份。
  - **Claude 套餐额度**：Claude Max、Ultra 订阅每月附带的 API 额度（Max 每月 $100、Ultra 每月 $200）。在 claude.ai 领取并关联 Console 组织后，到 Claude 控制台新建 API Key，按普通 Claude 供应商添加即可。
  - Coding Plan、Token Plan 这类编程套餐的条款只允许在编程工具里使用，阅读翻译不在其列，所以不提供。
- **AI 代理**：在“设置 → 翻译与 AI”选“AI 代理”，填写自己部署的 HTTPS 中转地址，供应商的 Key 只留在服务器上。仓库里没有现成的代理服务端。

配置步骤和请求格式见维护说明的 [AI 大模型配置](docs/MAINTENANCE.md#ai-大模型配置) 和 [AI 代理协议](docs/MAINTENANCE.md#ai-代理协议)。

使用在线翻译或 AI 功能时，选中的文字和语言方向会发给所选服务商，必要时还会带上经过长度限制的邻近上下文，并可能产生费用。API Key 保存在设备的安全存储里（iOS 钥匙串、Android 加密存储），不写入书籍、日志、安装包或备份；建议给个人 Key 设置用量上限并定期轮换。公开分发或多人共用时，更适合用 AI 代理。代理的翻译请求带稳定的幂等键（`X-Jerreader-Idempotency-Key`），服务端可以据此合并短时间内的重复请求，避免重复计费。

### 本机数据边界

- 书籍、阅读位置、批注、生词和翻译历史默认只保存在设备上。
- 只有用到在线翻译、联网词典或 AI 功能时，相关文字才会发给对应的服务。
- 自动化测试使用 Mock 和本地 Stub，不访问真实的翻译账户，也不依赖外网。

## 开发与构建

iOS 是 SwiftUI + SwiftData 的原生工程；Android 用 Compose 和 Room，书库、翻译、查词和学习的 Kotlin 代码以及部分界面放在 `shared/` 模块。iOS 不链接 `shared/`，复习、备份清理、原句练习等规则由 `shared/parity/` 里的同一份对拍用例在两端分别测试。

需要带 iOS 18 SDK 的完整 Xcode（Xcode 16 或更高版本）和 JDK 17。测试使用 Mock 或本地 Stub，不需要真实的 API Key。

```sh
scripts/safe_xcodebuild.sh doctor
scripts/safe_xcodebuild.sh host-test
scripts/safe_xcodebuild.sh build
scripts/safe_android_build.sh
```

iOS 只通过 `scripts/safe_xcodebuild.sh` 构建，默认是 generic iOS device、不签名、不启动模拟器；Android 走 `scripts/safe_android_build.sh`。两者共用排队锁、串行执行，失败后先查原因，不自动重跑。规则见 [AGENTS.md](AGENTS.md) 和 [iOS 低负载验证](docs/IOS_SAFE_TESTING.md)，打开工程的步骤见维护说明的 [打开与运行](docs/MAINTENANCE.md#打开与运行)。

更多说明：[架构说明](docs/ARCHITECTURE.md) · [Android 构建与交付](docs/android/BUILD_AND_PACKAGE.md) · [维护说明](docs/MAINTENANCE.md) · [产品需求文档](Jerreader_PRD_v1.0.md)

## 项目结构

| 目录 | 用途 |
|---|---|
| `Jerreader/` | iOS App：SwiftUI、SwiftData 与 Readium Swift Toolkit |
| `JerreaderTests/`、`JerreaderUITests/` | iOS 单元测试和界面测试 |
| `androidApp/` | Android App：Compose、Room 与 Readium Kotlin Toolkit |
| `shared/` | Android 用的 Kotlin 共用模块；`shared/parity/` 是两端共用的对拍用例，`shared/dictionaries/` 是内置中日词典 |
| `scripts/` | 构建、测试和打包脚本 |
| `docs/` | 架构说明、各版本维护记录、历史交接记录和第三方许可 |

两端版本号通常保持一致：iOS 在 `Jerreader.xcodeproj` 的 `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION`，Android 在 `androidApp/build.gradle.kts`。1.7.1 是只打了 Android 包的修复版，没有单独发布；2.0.0 起两端重新同号。

- 两端都修的：登录 ChatGPT 套餐后，已经填好密钥的 DeepSeek 不再从供应商列表里消失，登录后的提示也如实说明翻译服务是否已经在用套餐；PDF 读到最后一页进度记为 100%；同一条语法讲解重复保存不再变成两条；备份或恢复进行中离开页面不会被打断。

**1.7.1（70，只有 Android，没有单独发布）** 修复 [议题 #2](https://github.com/WZR0821/Jerreader/issues/2) 反馈的两个问题。iOS 没有这两个问题，停在 1.7.0（验证情况见 [1.7.1 维护记录](docs/RELEASE_1.7.1_2026-11-18.md)）：

- 滚动阅读时，左右滑动不再切换章节。以前手指稍微横移一点就会跳到相邻章节，丢掉阅读位置。滚动阅读时底栏的“上一页 / 下一页”切到上一章 / 下一章，屏幕左右边缘的轻点不再翻页。竖排书不变，仍然滑到边缘换章。

## 已知限制

- iOS 提供的是未签名 IPA，安装前要自己签名。
- Android 沿用测试分发用的 Debug 证书，不等同于应用商店的正式签名；APK 只含 arm64-v8a。
- iPad 版暂停开发，没有专门的适配和验收。
- 语音、听书和语速设置暂时关闭，只有复习卡里的日文朗读可用。
- Apple 系统翻译第一次使用某个语言方向时，可能需要联网下载语言包。
- 在线词典、第三方 AI 服务和自建代理的可用性与费用由相应服务商决定。
- OCR 和自动断句是阅读辅助，复杂版面下可以改用长按选区精确选择。
- 2.0.0 和 2.0.1 的自动化验收都在模拟器上完成，测试使用 Mock，没有连接真实的 AI 服务；ChatGPT 套餐没有用真实账号登录过，登录不上时请改用 API Key。
